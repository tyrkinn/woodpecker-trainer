# Woodpecker Trainer

Личный тренажёр тактики по методу Woodpecker. Один фиксированный набор задач из базы Lichess, каждый цикл быстрее предыдущего, аналитика ошибок по мотивам. Всё локально, без бэкенда, работает офлайн как PWA.

## Быстрый старт

```bash
pnpm install
pnpm test            # все тесты: core, генератор, слой данных
pnpm dev             # тренажёр на http://localhost:5173 (с --host — доступен с телефона в той же сети)
```

## 1. Набор задач

В приложение встроены два готовых набора по 400 задач Lichess (`--seed 42`): основной 1500–1900 и полегче 1300–1700. Рейтинг задач Lichess заметно выше рейтинга партий на chess.com, поэтому для цели ~1700 на chess.com основной — 1500–1900. Файлы лежат в `apps/web/public/sets/` и доступны офлайн.

Свой набор под другой рейтинг или темы:

Скачай базу (≈250 МБ) или дай генератору читать её прямо по сети:

```bash
curl -O https://database.lichess.org/lichess_db_puzzle.csv.zst

npx tsx tools/set-generator --min-rating 1300 --max-rating 1700 --count 400 --seed 42 --out sets/base-1300.json
# то же самое короче:
pnpm gen --seed 42
```

- Без `--input` берётся `./lichess_db_puzzle.csv.zst`, а если его нет — база читается потоком с database.lichess.org, без сохранения на диск.
- Файл читается потоком, в памяти держится только пул кандидатов. Распаковка — системный `zstd`, если он установлен (`brew install zstd`), иначе fzstd. Встроенный в Node zstd не годится: база Lichess в seekable-формате со skippable-кадрами, на которых он ломается. Полная база (6,2 млн задач) — около 6 секунд с системным zstd.
- `--seed` обязателен. Тот же seed и те же параметры дают байт-в-байт тот же файл, включая `createdAt` — это дата данных (mtime файла или Last-Modified), её можно задать `--created-at`.
- Заголовок CSV сверяется с ожидаемым; если Lichess поменяет колонки, генератор упадёт с понятным списком недостающих.
- Все параметры: `pnpm gen --help`.

Как устроен отбор: фильтры → каждой задаче ключ `hash(seed:id)` → берём задачи с наименьшими ключами, пропуская те, что подняли бы долю какого-то мотива выше `--max-theme-share`. Мета-теги (`short`, `endgame`, `crushing`, `mate`…) не балансируются. Каждая выбранная задача проверяется по правилам через chess.js. Итог сортируется по рейтингу.

## 2. Тренироваться

Открой приложение → «Импортировать набор» → выбери JSON. Дальше главная кнопка всегда ведёт в задачу, на которой остановился.

- **Цикл 1** — на точность, без цели. **Цель цикла N+1** = активное время цикла N × коэффициент (0.5 по умолчанию, минимум 0.3, меняется в настройках набора).
- **Одна попытка**: первый неверный ход — провал, показывается решение. «Не знаю» — тоже провал. Мат другим ходом засчитывается.
- **Время** считается только активное: сворачивание, блокировка телефона и пауза его останавливают.
- После каждой задачи попытка и прогресс цикла пишутся одной транзакцией — закрытие приложения теряет максимум текущую задачу.
- **«Только ошибки»** после цикла прогоняет проваленные задачи. Не считается циклом и не влияет на цель.
- Хоткеи: пробел/Enter — дальше, `F` — перевернуть, `Esc` — пауза.
- **Бэкап** на главной: весь IndexedDB одним JSON-файлом — для переноса на другое устройство.

## 3. Поставить на телефон

Приложение выкладывается на GitHub Pages при каждом пуше в `main`: https://tyrkinn.github.io/woodpecker-trainer/. На телефоне открой ссылку → «Добавить на главный экран». После первой загрузки работает в авиарежиме.

Сборка относительная (`base: './'`), так что `apps/web/dist` можно положить в любую папку любого статического хостинга.

## Структура

```
packages/core        логика задачи, циклов, статистики и отбора набора — без UI, вся под тестами
tools/set-generator  CLI генератора (потоковое чтение csv.zst)
apps/web             Svelte 5 + Vite, chessground, Dexie, PWA
```

Схема IndexedDB версионируется в `apps/web/src/lib/db.ts`: любое изменение — новая `version(N)` с `upgrade()`.

## Проверено

- 69 тестов Vitest: логика задачи (автоход, проверка хода, альтернативный мат, превращение, рокировка в UCI в обе стороны, многоходовки), циклы (цель, пауза, восстановление с cursor, «только ошибки»), генератор на фикстурном CSV (каждый фильтр, детерминизм, лимит доли темы, сортировка, .zst), статистика на синтетическом логе, слой IndexedDB.
- Стартовый бандл без доски — ~76 КБ gzip, доска грузится лениво вместе с экраном решения.
- Lighthouse, мобильный профиль: Performance 98, Accessibility 100, Best Practices 100.
